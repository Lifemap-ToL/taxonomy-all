# Greek vernacular names

The Greek pipeline uses the shared NCBI Taxonomy, GBIF Backbone, Catalogue of Life, and iNaturalist taxonomy downloads plus a Greek-language Wikidata extract. The final `TAXONOMIC-VERNACULAR-EL-LATEST.txt` is generated by `python3 -m taxonomy_all build el` and contains four tab-separated columns: NCBI taxid, current NCBI scientific name, vernacular name, and source IDs.

Source scientific names are matched against NCBI scientific names and synonyms. Wikidata can also provide a direct NCBI taxid. Unmatched source records are written to the local `unmatched.tsv` report.
