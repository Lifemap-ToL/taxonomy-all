# Spanish vernacular names

The Spanish pipeline uses the shared NCBI Taxonomy, GBIF Backbone, Catalogue of Life, and iNaturalist taxonomy downloads plus a Spanish-language Wikidata extract. The final `TAXONOMIC-VERNACULAR-ES-LATEST.txt` is generated by `python -m taxonomy_all build es` and contains four tab-separated columns: NCBI taxid, current NCBI scientific name, vernacular name, and source IDs.

Each vernacular name is associated with NCBI by exact matching of the source's scientific name against NCBI scientific names and synonyms. Wikidata can additionally provide a direct NCBI taxid; GBIF and iNaturalist identifiers are not used to transfer names. Every valid NCBI match is kept, including links from one scientific name to multiple taxids. Unmatched source records are listed for review.

Regional Spanish-language sources can be added to this language pipeline later without changing the shared source downloads or the backend TSV format.
